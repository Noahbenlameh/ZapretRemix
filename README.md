# ZapretRemix

Дружелюбная LuCI-надстройка поверх [`zapret2`](https://github.com/bol-van/zapret2) ([`remittor/zapret-openwrt`](https://github.com/remittor/zapret-openwrt)) для OpenWrt — диагностика блокировок по домену, точечное закрепление стратегии под конкретный сервис и управление обходом DPI через понятный веб-интерфейс вместо ручного SSH/uci.

**Не форк и не замена `zapret2`** — работает с тем же `/etc/config/zapret2` и теми же скриптами (`sync_config.sh`, `def-cfg.sh`, `blockcheck2.sh`), переиспользует готовые JS-модули `luci-app-zapret2` там, где это возможно.

## Зачем нужна надстройка, если `zapret2` и так работает

`zapret2` — мощный движок обхода DPI, но всё, что сложнее «запустить/остановить», требует ручного `uci`/SSH: подобрать стратегию под сайт, понять — это вообще DPI-блок или провайдер просто подменяет DNS, закрепить особые настройки под один сервис, не трогая остальной трафик. ZapretRemix закрывает именно этот разрыв:

| Без ZapretRemix | С ZapretRemix |
|---|---|
| Подбор стратегии — руками через `blockcheck2.sh` и правку конфига | Вкладка «Рекомендации»: вводишь домен → диагноз (DNS-подмена / IP-блок / DPI-блок) → автоперебор пресетов за 30–40 сек |
| Одна стратегия на весь трафик | «Закреплённые»: своя стратегия + свой DNS под конкретный сервис, не трогая остальное |
| Сервис — это не один домен (видео/CDN/API у YouTube, Discord и т.д.), легко забыть половину | Готовые наборы доменов одной кнопкой (YouTube, Discord, Instagram, Twitter, Netflix, Steam и др.) |
| DNS-подмена провайдером лечится отдельным гуглением/правкой `/etc/config/dhcp` | Переключатель DNS прямо на дашборде (публичный / провайдера по IP / свой) |
| Ошибся с настройкой — рискуешь потерять доступ к роутеру | Применение с автооткатом: не подтвердил за 20 сек — вернулось как было |
| SOCKS5/HTTP-прокси без домена — стратегию под них применить нечем | Экспериментальная вкладка «Прокси по портам» — «слепые» стратегии по позиции байт + автотест, помогло или нет |

## С чего начать

| # | Шаг | Что делать |
|---|---|---|
| 1 | Проверь статус | «Дашборд» — работает ли демон, какой режим фильтрации активен |
| 2 | Сайт не открывается? | «Рекомендации» — введи домен, получишь диагноз и готовую стратегию |
| 3 | Сервис из нескольких доменов | Например YouTube = `youtube.com` + `googlevideo.com` + ещё несколько — «Закреплённые» закрепляют всю группу разом |
| 4 | Домены неизвестны | «Поиск по приложению» — захвати DNS-запросы, пока пользуешься приложением, и закрепи найденное |

## Все вкладки коротко

| | Вкладка | Что делает |
|---|---|---|
| 📊 | **Дашборд** | Статус демона, старт/стоп, режим фильтрации, глубина пакетов, DNS |
| 🩺 | **Рекомендации** | Диагноз по домену (DNS/IP/DPI) + автоперебор стратегий, можно пулом связанных доменов |

| 📌 | **Закреплённые** | Домены (можно группой) со своей стратегией и/или DNS — независимо от общих настроек |
| 🧪 | **Прокси по портам** | Экспериментально: то же для SOCKS5/HTTP-прокси по порту, без домена |

| 💾 | **Экспорт/Импорт** | Резервная копия всех настроек ZapretRemix одним файлом — и восстановление из него |
| ⬆️ | **Обновление** | Обновление самого ZapretRemix |

## Возможности подробнее

**Режим фильтрации (Дашборд)**

> [!TIP]
> **«Умный автоматический режим» — рекомендуется по умолчанию.** Демон сам следит за признаками вмешательства DPI (повторные передачи, обрывы) и решает, каким хостам нужна помощь. Хороший баланс для повседневного использования.

> [!NOTE]
> **«Только выбранные сайты».** Стратегия применяется только к доменам из «Ресурсы» / «Закреплённые». Предсказуемо и легче для роутера, но сайты нужно добавлять вручную.

> [!WARNING]
> **«Выключено» — только для диагностики.** Стратегия применяется вообще ко всему трафику в доме, без разбора домена. Самый широкий охват, но и самая высокая нагрузка на роутер.

**Глубина обработки пакетов.** Сколько пакетов каждого нового соединения обрабатывает демон. «Первые пакеты» хватает почти всегда — всё решается в момент установки соединения. «Всегда» нужно, только если сайт обрывается не сразу, а глубоко внутри долгой сессии — но это ощутимо дороже по нагрузке.

**DNS.** Провайдер может не только резать/обрывать соединения (это лечит `zapret2`), но и напрямую подделывать DNS-ответы — переключение DNS лечит именно это, отдельно от всего остального: DNS провайдера (авто/по IP), публичный DNS (8.8.8.8, 1.1.1.1) или свой резолвер.

**Закреплённые — зачем группа доменов.** Один пункт может держать сразу несколько доменов с общей стратегией и DNS — у сервиса обычно есть отдельные домены для самого контента (видео/CDN/API), не только для главного сайта.

> [!WARNING]
> **Частая ошибка** — закрепить только `youtube.com`: сайт откроется, а видео — нет, потому что оно грузится с `googlevideo.com`, который остался на старых настройках. На вкладке есть готовые наборы («Набор: …») именно для этого.

**Прокси по портам — экспериментально.**

> [!CAUTION]
> Ниже гарантий, чем у остальных вкладок. Для SOCKS5/HTTP-прокси нет домена, который можно распознать — стратегия применяется «вслепую» по фиксированной позиции байт. Работает, только если провайдер режет именно по DPI-паттерну на этом порту, не по IP — автотест на вкладке честно покажет, помогло что-то или нет.

**Экспорт/Импорт.** Резервная копия всего, чем управляет ZapretRemix (режим, глубина пакетов, сырая стратегия, DNS-режим, Закреплённые с их DNS, Прокси по портам, Ресурсы, пул DNS) — одним JSON-файлом.

> [!NOTE]
> Это снимок конкретного роутера, не универсальный переносчик между разными моделями — восстанавливать лучше на том же роутере или на роутере с той же версией `zapret2`.

**Тест и анализ.** Глубокая, но медленная проверка (`blockcheck2.sh`, перебирает десятки стратегий, может идти 10–30+ минут) — демон на время теста останавливается. Для быстрой ежедневной проверки используй «Рекомендации»: тот же принцип, но за 30–40 секунд по 4 основным пресетам.

**Если что-то пошло не так.**

> [!TIP]
> **Применил настройку и что-то сломалось** — ничего нажимать не нужно, LuCI сама следит за доступностью роутера и автоматически откатывает изменение, если связь пропала.

> [!CAUTION]
> **Роутер совсем недоступен** — подожди штатный откат LuCI (около минуты) либо перезагрузи роутер физически: `zapret2` запустится с последним сохранённым конфигом.

> [!NOTE]
> **Полностью выключить обход** — Дашборд → «Стоп». Интернет у всех в доме продолжит работать как обычно, просто без обхода блокировок.

## Техническая часть

ZapretRemix — набор LuCI JS-вьюх (`www/luci-static/resources/view/zapretremix/*.js`) и shell-скриптов (`/opt/zapretremix/*`), которые работают строго через штатные интерфейсы `zapret2` — `uci`, `sync_config.sh`, `def-cfg.sh`, `blockcheck2.sh` — и никогда не редактируют файлы `/opt/zapret2/*` напрямую. Файлы `/opt/zapret2/*` считаются вендорскими; собственный код и состояние (`pins.json`, списки доменов, шаблоны стратегий) живут отдельно в `/opt/zapretremix/*`.

**Пайплайн закрепления.** Любая вкладка, добавляющая или снимающая закрепление (домен или порт), в конце вызывает один и тот же `rebuild-opt.sh <preset>`:
1. через `def-cfg.sh`/`set_cfg_nfqws_strat` генерирует «чистый» `NFQWS2_OPT` под текущий глобальный пресет;
2. дописывает поверх блоки закреплений (домены и порты отдельно) с дедупликацией `--blob=` — иначе дубли имён между глобальным пресетом и пином тихо роняют демон;
3. восстанавливает `MODE_FILTER` и поля глубины пакетов, которые `set_cfg_nfqws_strat` иначе сбрасывает как побочный эффект.

Сборка «сброс + дописывание» намеренно сделана одним shell-скриптом, а не пошагово через клиентский `uci.js`: чтение uci-значения, только что записанного отдельным shell-процессом, оказалось ненадёжным на практике — такое чтение делается только внутри одного скрипта (`uci get/set/commit`), не через клиентский read-back.

`pins.json` хранит закрепления как `{ id, domains: [...], preset, dns }` — один пункт может держать несколько доменов с общей стратегией/DNS, что и решает проблему «забытого CDN-домена» выше.

Применение любой настройки идёт через штатный механизм отката LuCI: правки временные, пока не подтверждены явно, иначе автоматически откатываются, если роутер стал недоступен.

## Структура

Дерево внутри репозитория 1:1 повторяет пути на роутере (`usr/...`, `www/...`) — `install.sh` просто копирует их на место.

## Установка

Нужен уже установленный и настроенный `zapret2`/`luci-app-zapret2` — ZapretRemix только надстройка над ним, сам его не ставит. На роутере по SSH:

```sh
rm -rf /tmp/zr && mkdir -p /tmp/zr
curl -fsSL -o /tmp/zr.tar.gz https://api.github.com/repos/Noahbenlameh/ZapretRemix/tarball/master
tar -xzf /tmp/zr.tar.gz -C /tmp/zr
sh /tmp/zr/*/install.sh
```

Потом в браузере — жёсткое обновление страницы (Ctrl+Shift+R / Cmd+Shift+R), Services → ZapretRemix.
