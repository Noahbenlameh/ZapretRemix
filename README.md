# ZapretRemix

Дружелюбная LuCI-надстройка поверх `zapret2`/`luci-app-zapret2` (remittor/zapret-openwrt) — управление стратегиями, ресурсами, тестирование и общий обход блокировок через понятный интерфейс, вместо ручного редактирования uci-опций.

Не форк и не замена `zapret2` — работает с тем же `/etc/config/zapret2` и теми же скриптами (`sync_config.sh`, `def-cfg.sh`, `blockcheck2.sh`), переиспользует готовые JS-модули `luci-app-zapret2` (`view.zapret2.env`) там, где это возможно.

## Благодарности / лицензии используемых проектов

`ZapretRemix` не содержит и не распространяет чужой исходный код — только вызывает уже установленный на роутере `zapret2` через его штатные интерфейсы (`uci`, shell-скрипты), плюс во время выполнения импортирует JS-модуль `env.js` из `luci-app-zapret2`.

- [`bol-van/zapret2`](https://github.com/bol-van/zapret2) — движок обхода DPI (`nfqws2` и т.д.). Без файла лицензии в репозитории на момент проверки (2026-08-24) — мы не копируем и не распространяем его код, только используем уже установленную программу.
- [`remittor/zapret-openwrt`](https://github.com/remittor/zapret-openwrt) (включая `luci-app-zapret2`, чей `env.js` мы импортируем) — лицензия **MIT**.

## Статус

**Фаза 1 — Дашборд (в разработке):** статус демона, Старт/Стоп/Рестарт, режим фильтрации (`none`/`hostlist`/`autohostlist`) человеческими словами, кнопки глубины обработки пакетов (10/100/1000/всегда), безопасное применение настроек с таймером автоотката (20 сек, если не подтвердить).

Дальше по плану: Стратегии (пресеты из `def-cfg.sh`), Ресурсы (управление hostlist/exclude списками), Тест и анализ (обёртка над `blockcheck2.sh`), Логи, поиск стратегии по имени приложения.

## Установка (пока вручную, без GitHub-инсталлятора)

С Мака на роутер (замени IP на актуальный):
```sh
scp -r ZapretRemix root@192.168.85.1:/tmp/
ssh root@192.168.85.1 'sh /tmp/ZapretRemix/install.sh'
```

Потом в браузере: жёсткое обновление страницы (Ctrl+Shift+R / Cmd+Shift+R), затем Services → ZapretRemix.

## Структура

Дерево внутри репозитория 1:1 повторяет пути на роутере (`usr/...`, `www/...`) — `install.sh` просто копирует их на место.
